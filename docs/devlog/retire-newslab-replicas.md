# NewsLab exporter 종료 설정 기록

2026-11-07, 운영에서 이미 종료된 exporter의 배포 희망 상태를 replicas 0으로 맞췄다.
Argo CD 연결이 없으면 Git 파일만으로 Pod가 생성되지 않지만, 이후 설정을 다시
적용하더라도 운영 종료 상태가 유지되도록 했다.

기존 값은 1이었다. 재개할 때도 중복 지표 수집과 DB 조회 부하를 피하도록
1개만 실행한다는 설명을 남겼다. 코드, DB 접속, 서비스와 Secret은 변경하지 않았다.
초기에는 로컬 파일만 변경했다. 이후 사용자의 요청으로 커밋·푸시와 main 대상 PR
발행을 진행하며, 서버 적용과 병합은 수행하지 않는다.
